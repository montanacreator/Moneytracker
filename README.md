# Moneytracker

Persönlicher Einnahmen- und Ausgaben-Tracker mit mehreren Konten, Budgets, regelmäßigen Buchungen und Sparzielen.

## Dateien
- `index.html` – Seitenstruktur
- `css/style.css` – Design
- `js/app.js` – Logik
- `assets/` – App-Icon (M)

## Online stellen (GitHub Pages)
1. Alle Dateien in ein GitHub-Repository hochladen (die Ordnerstruktur beibehalten).
2. Im Repository: Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
3. Nach kurzer Zeit ist die App unter `https://DEIN-NAME.github.io/REPO-NAME/` erreichbar.

## Auf dem iPhone als App
Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Das M-Icon wird übernommen, die App öffnet sich im Vollbild.

## Hinweis
Alle Daten liegen nur im Browser des jeweiligen Geräts (localStorage).
